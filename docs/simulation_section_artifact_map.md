# Simulation Section Artifact Map

The paper-facing simulation artifacts are generated by:

```bash
Rscript scripts/sample_size/make_simulation_section_artifacts.R
```

The script uses the completed 25-rep component-profile runs for matched
Spectral-MAP/Gibbs comparisons at `p = 500, 1000`, appends the completed
Spectral-MAP recovery rows at `p = 1500, 2000`, and uses the original recovery
run for end-to-end timing.

## Supplement

The `supplement/` figure directory contains separate faceted boxplots for
factor scores, response probabilities, loadings, intercepts, mixture means,
mixture variances, mixture weights, Hamming accuracy, exact-profile accuracy,
and mean component ARI under each mixture configuration.

The pooled recovery and rotation tables are:

- `table_recovery_supplement.tex`
- `table_rotation_ablation_supplement.tex`

## Runtime wording

The completed timing table supports pooled speed-ups of `8.0x` to `11.6x`
across the four `(H, G)` configurations. Across the 24 individual
`(n, p, H, G)` cells, the observed range is approximately `5.8x` to `15.7x`.
The draft phrase `7--22 times faster` should therefore be updated before the
paper is finalized.
